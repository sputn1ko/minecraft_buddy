# Minecraft Buddy — бот-напарник для Minecraft Java

Первая версия: бот подключается к миру по LAN, умеет следовать за игроком, идти к игроку, собирать близлежащие блоки по имени, автоматически есть при наличии еды в инвентаре, отвечать на простые команды и атаковать ближайших враждебных мобов в режиме охраны.

## Что потребуется

- Minecraft Java Edition на ПК.
- Windows 10/11.
- Node.js LTS: https://nodejs.org/
- Интернет для первой установки библиотек.
- Мир Minecraft открыт в LAN.

## Установка

1. Установи Node.js LTS с официального сайта. В установщике оставь стандартные параметры.
2. Распакуй архив `MinecraftBuddy.zip` в обычную папку, например `C:\\MinecraftBuddy`.
3. Запусти Minecraft Java и загрузи свой одиночный мир.
4. Нажми `Esc` → `Открыть для сети` / `Open to LAN` → `Начать мир LAN` / `Start LAN World`.
5. Посмотри в игровом чате сообщение вроде `Local game hosted on port 54321`. Запомни порт.
6. Открой папку `MinecraftBuddy` и двойным щелчком запусти `start.bat`.
7. При первом запуске программа скачает библиотеки. Это может занять несколько минут.

### Если LAN-порт не 25565

По умолчанию бот подключается к `127.0.0.1:25565`. У одиночного мира LAN порт часто случайный. Поэтому перед запуском открой файл `start.bat` через Блокнот и добавь две строки после `cd /d "%~dp0"`:

```bat
set MC_HOST=127.0.0.1
set MC_PORT=54321
```

Замени `54321` на порт из игрового чата. Сохрани файл и запусти его снова.

## Команды

Команды можно вводить в консоль бота или в игровой чат с префиксом `!buddy`.

| Команда | Что делает |
|---|---|
| `help` | Список команд |
| `follow` | Следовать за игроком, написавшим команду в чате |
| `come` | Подойти к игроку |
| `stop` | Остановиться и прекратить текущие действия |
| `guard` | Включить/выключить охрану и бой с ближайшими враждебными мобами |
| `collect oak_log` | Собрать рядом блоки указанного типа |
| `mine iron_ore` | То же, что collect, для указанного блока |
| `status` | Показать координаты и режим |
| `say Привет!` | Написать сообщение в игровой чат |

Примеры в игровом чате:
- `!buddy follow`
- `!buddy come`
- `!buddy guard`
- `!buddy collect oak_log`
- `!buddy status`

Имена блоков вводятся на английском и в формате из Minecraft, например `oak_log`, `cobblestone`, `iron_ore`, `coal_ore`.

## Важные ограничения

- Это первая рабочая основа, а не автономный человекоподобный ИИ. Команды понимаются по фиксированному списку; для свободного общения с языковой моделью понадобится отдельная интеграция и обычно API-ключ.
- Бот не строит произвольные здания, не крафтит полный набор предметов и не планирует долгую добычу самостоятельно в этой версии.
- Режим боя лучше работает, когда у бота есть меч или топор в инвентаре. Он не гарантирует идеальное распознавание угроз.
- Успешность входа с `auth=offline` зависит от версии и настроек локального мира. Используй это только для собственного локального мира. Если соединение отклоняется, см. раздел ниже.
- Бот — отдельный игрок. Он не появится, пока мир не открыт для LAN и процесс бота не запущен.
- Не публикуй порт LAN в интернете и не отключай защиту Windows без понимания последствий.

## Если не подключается

1. Проверь, что мир открыт для LAN и порт совпадает.
2. Убедись, что `MC_HOST=127.0.0.1`, если Minecraft и бот на одном ПК.
3. Проверь, что версия Minecraft поддерживается Mineflayer: https://github.com/PrismarineJS/mineflayer
4. Если видишь `ECONNREFUSED`, обычно порт неверный или LAN-мир закрыт.
5. Если сообщение связано с проверкой имени/авторизацией, локальный мир может не принимать offline-подключение. Тогда потребуется отдельный легальный аккаунт Minecraft и вход через Microsoft: в `start.bat` перед `call npm start` добавь `set MC_AUTH=microsoft`. Не вводи пароль в код или незнакомые сайты; авторизация проходит через официальный поток входа Microsoft.
